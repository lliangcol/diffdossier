# Support policy

DiffDossier has public beta Pre-releases but no stable release. The latest
`main` commit is a development snapshot and carries no compatibility or
platform-support promise.

Support routing is maintained by Liu Liang through the repository owner account
[`lliangcol`](https://github.com/lliangcol); `liuliang1` is the established
maintainer handle for the same person. See
[`docs/governance/identity-and-roles.md`](docs/governance/identity-and-roles.md)
for the role boundary.

Use public GitHub issues for reproducible bugs and narrowly scoped feature
requests that contain only synthetic or already-public data. Do not attach
private source, repository paths, packets, results, logs, credentials, or other
sensitive evidence. Follow `SECURITY.md` for vulnerabilities or suspected
secret exposure.

Before stable support is declared, this file will list supported version lines,
operating systems, architectures, response expectations, and end-of-support dates.
The current beta compatibility and non-support boundaries are in
[`docs/beta-compatibility.md`](docs/beta-compatibility.md).

## Beta response boundary

Beta reports are best-effort: there is no response-time SLA, guaranteed fix,
or supported-version window. The maintainer reviews the beta support boundary
and release cadence every 4–6 weeks, but this is a planning target rather than
a promise. A release may be skipped or deferred when verification, security,
capacity, or maintainer availability is insufficient.
