# Support policy

DiffDossier has no stable or public beta release. The latest `main` commit is a
development snapshot and carries no compatibility or platform-support promise.

Use public GitHub issues for reproducible bugs and narrowly scoped feature
requests that contain only synthetic or already-public data. Do not attach
private source, repository paths, packets, results, logs, credentials, or other
sensitive evidence. Follow `SECURITY.md` for vulnerabilities or suspected
secret exposure.

Once releases begin, this file will list supported version lines, operating
systems, architectures, response expectations, and end-of-support dates.
