# Public roadmap

This roadmap describes direction, not dates, delivery promises, or release
approval. Current evidence and gates remain authoritative over this summary.

| Phase | Focus | Exit evidence |
|---|---|---|
| Beta product closure | Accurate release/platform facts, safe installation path, reproducible case, community entry points. | P0 exit tasks in the [productization plan](plans/2026-07-27-productization-todo.md) are complete. |
| Guided local workflow | Safe onboarding, stable evidence contracts, Provider boundaries, risk quality and offline reporting. | Phase 1 entry/exit gates are complete; no local result is represented as remote approval. |
| Ecosystem and distribution | Public cases, optional reporters, policy packs, package-channel designs, and release cadence. | Phase 2 gates and per-channel authorization/evidence are complete. |
| Stable-release preparation | Compatibility, independent review, long-term reliability, support capability, audit and immutable candidate evidence. | v1 gates and separate release authorization are complete. |

## Non-commitments

- No date, feature, platform tier, Provider, package channel, or stable-release
  promise is implied.
- External writes, real Providers, public data, package publication, security
  disclosure, tags, Releases, and repository settings always need their own
  exact authorization.
- The current beta scope and limitations are in
  [beta compatibility](beta-compatibility.md); the task-level source of truth
  is the [productization plan](plans/2026-07-27-productization-todo.md).
